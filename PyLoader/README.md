# PyLoader

PyLoader is a responsive, password-protected cloud audio workspace. It searches YouTube videos, queues audio conversion to MP3, and lets signed-in users download the result from a phone, tablet, or desktop browser. The attendance application at the repository root is unchanged.

## Deploy on Render

1. In Render, choose **New → Blueprint** and connect this repository.
2. Select the blueprint file at `PyLoader/render.yaml` if Render asks for its location.
3. Set the required `ACCESS_PASSWORD` environment variable to a strong private password.
4. Deploy. Render builds the Docker image, installs FFmpeg and Python dependencies, and provides an HTTPS URL.
5. Open that URL on any device and sign in.

The included Render service uses a paid Starter plan. Confirm current provider pricing before deploying. This source has been added to GitHub, but it is not yet a live hosted website; deployment must be completed in your hosting account.

## Important use limitation

Use this only for audio you own or are authorized to download. Respect YouTube's terms, copyright, and creators' rights. This app does not bypass DRM, private-video restrictions, or other access controls. A confirmation is required before each conversion, but it is not an automated rights verification system.

## Storage and configuration

- MP3 files are stored temporarily on the service's local filesystem and cleaned after roughly six hours.
- Files are not guaranteed to survive a restart or redeploy. This version does not provide a permanent cloud music library.
- Access uses one shared password; anyone who receives it can use the app. Do not publish the password.
- `APP_SECRET` signs sessions and is generated by Render's blueprint.
- `ACCESS_PASSWORD` is the shared login password and must be set before public use.
- `MAX_WORKERS` controls concurrent conversion workers (default 2).
- Search is rate-limited per IP. Larger public deployments need managed storage, per-user accounts, quotas, abuse controls, and a persistent job queue.

## Local development

Requires Python 3.12+ and FFmpeg.

```bash
python -m venv .venv
pip install -r requirements.txt
```

Set `APP_SECRET` and `ACCESS_PASSWORD`, then run `python app.py`. Open http://127.0.0.1:8080.
